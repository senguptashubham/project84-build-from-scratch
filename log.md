# Time log

One row per work session, so an item can have several. Add a line when you tick an item. `Minutes` is your actual time; leave it empty if you don't know (it then counts as unknown, not zero). `python master.py` turns this into the *Actual hours* and *Actual / planned* columns on the Progress table in `README.md`.
