## theory/

The theory track (`THEORY_README.md`, modules M0 to M9, the per-topic notes, cheat sheets and Q&A) was **retired in Nov 2026**. It is kept here, unchanged, for reference, and nothing in the live plan reads it.

Why: the track made the plan heavy. Writing polished notes for every topic competed with the thing the project is for, which is writing code from a blank file and deriving results on paper. Project 84 now has two tracks, code and derivations. Book reading (MML, Murphy PML, D2L) happens outside this repo and is not tracked here; a problem is read up only as far as it takes to solve it.

Links inside `archive/theory/` still work among themselves. Links from the live plan into it were removed. `master.py` no longer parses it.
