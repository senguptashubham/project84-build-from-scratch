## Precision
#### Binary 
Out of all the predicted positives, how many were actually (truly) positives.
$$ Precision = \frac{True\,Positives}{True\,Positives + False\,Positives} $$
#### Multi-class
**Idea :** Out of all the predictions resulting a given class, how many were actually from that given class. 
#### Measures :
*How accurate the positive predictions are*
## Recall (*Sensitivity*)
#### Binary
Out of all the actual positives, how many were correctly predicted as positives.
$$ Recall = \frac{True\,Positives}{True\,Positives + Flase\,Negatives} $$
#### Multi-class
**Idea :** Out of all the candidates of a given class, how many were predicted to be from that class.
#### Measures :
*Coverage of actual positive sample*
## F1
Harmonic mean of `Precision` and `Recall`, to capture the overall performance in a balanced manner.
$$ F1 = \frac{2 \times Precision \times Recall}{Precision + Recall} $$
If we express in terms of True Positives, False Positives, False Negatives:
$$ F1 = \frac{True\,Positives}{True\,Positives + \frac{1}{2}(False\,Positives + False\,Negatives)} $$

This metric is particularly useful for unbalanced classes
## Micro, Macro, Weighted Average

```Python

(function) def precision_score(
 y_true: MatrixLike | ArrayLike,
 y_pred: MatrixLike | ArrayLike,
 *,
 labels: ArrayLike | None = None,
 pos_label: str | int = 1,
 average: Literal['micro', 'macro', 'samples', 'weighted', 'binary'] | None = "binary",
 sample_weight: ArrayLike | None = None,
 zero_division: int | Literal['warn'] = "warn"
) -> (Float | ndarray[_AnyShape, dtype[Any]])
```

```
average: Literal['micro', 'macro', 'samples', 'weighted', 'binary'] | None = "binary" 
```
this is *common* for `recall_score`, `f1_score` as well

- `average = 'micro'` says the function has to consider total true positives, false negatives or false positives (irrespective of the prediction for each label in the dataset)
- `average = 'macro'` says the function has to compute for each label, and returns the average without considering the proportion for each label in the dataset.
- `average = 'weighted'` says the function to compute for each label, and returns the average considering the proportion for each label in the dataset.
- `average = 'samples'` says the function to compute for each instance, and returns the average, used in multilabel classification.

## Accuracy
Out of all the candidates, how many were predicted correctly by the model.
$$ Accuracy = \frac{True\,Positive + True\,Negative}{True\,Positive + True\,Negative + False\,Positive + False\,Negative} $$
``` Python

(function) def accuracy_score(  
y_true: MatrixLike | ArrayLike,  
y_pred: MatrixLike | ArrayLike,  
*,  
normalize: bool = True,  
sample_weight: ArrayLike | None = None  
) -> Float
```

As accuracy gets calculated over the whole sample space, there is no average parameter.
In multilabel classification, this function computes subset accuracy: the set of labels predicted for a sample must _exactly_ match the corresponding set of labels in `y_true`.
